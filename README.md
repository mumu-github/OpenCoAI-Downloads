| 系统 | 状态 |
| --- | --- |
| Windows x64 | 安装包待发布，当前暂无可下载版本 |

通过验收的安装包将在 [Releases](https://github.com/mumu-github/OpenCoAI-Downloads/releases) 提供，下载无需 GitHub 登录。暂未发布的版本不提供下载链接。

## 安装与更新

- Windows 内测版暂未签名，系统可能提示未知发布者。安装前核对文件名、版本与 `SHA256SUMS.txt` 中的校验值。
- 当前采用下载安装包后手动更新。升级前备份本机数据，保留原账号与会话目录。
- 企业账号由管理员分配；安装后按企业提供的连接信息登录。

源码不在此分发仓库中。
