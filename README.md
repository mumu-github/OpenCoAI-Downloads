# OpenCoAI

**让 AI 按你们的方法做事。**

OpenCoAI 是面向企业的 AI 工作平台。员工在桌面端交办任务、检查成果，也可以配置自己的智能体，写下它的职责和工作方法。

一项工作常有自己的口径：哪些资料可以用，表格怎样核对，报告需要包含什么，遇到异常该找谁确认。这些要求可以写进智能体的工作方法，下一次同类任务继续使用。

智能体可以处理资料、生成交付文件。你打开文件检查结果，指出遗漏或口径问题，再修改工作方法，让新任务用上改好的版本。企业管理员负责配置模型、知识、技能和工具，以及员工的使用权限。

## 从一项具体工作开始

例如，把采购申请、实际采购记录和核对规则交给智能体，提出这样的要求：

> 按我们的核对规则整理采购汇总，列出申请与实际记录的差异。缺少的资料单独列出来，生成文件供我检查。

你可以查看交付文件，继续追问或要求修改。如果某种例外处理以后也要沿用，就把它补进工作方法。任务反馈和成果确认由员工完成；保存后的新方法用于新任务，已有任务保留创建时的版本。

我们希望，熟悉业务的人能把自己的做法交给 AI，做过的改进能在下一次工作里继续发挥作用。当前内测先做好个人智能体、任务处理和成果检查；成熟方法的发布审核与团队共享将在后续开放。

## 安装和更新

Windows 内测包未签名，安装时可能提示“未知发布者”。发布页会附校验文件，安装前请核对下载的文件与 `SHA256SUMS.txt` 中的 SHA-256 值。

更新需要手动下载新安装包。覆盖安装前先备份本机数据，保留账号和会话目录。使用企业模型需要管理员分配的账号，连接地址见企业提供的说明。

遇到问题，可以在 [Issues](https://github.com/mumu-github/OpenCoAI-Downloads/issues) 写下系统版本、客户端版本和复现步骤。请不要附上密码或企业资料。
