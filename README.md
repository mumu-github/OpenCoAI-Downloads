# OpenCoAI 桌面版

OpenCoAI 是一个围绕本地文件工作的 AI 客户端。选一个工作文件夹开始会话，把资料和要求交给 AI；经常要做的事，可以配成智能体，把角色、工作方法和要用的能力留在那里。

我们在意做过的工作能接着用。一个智能体的不同会话共用工作目录，聊天记录各自保留。你可以打开交付文件检查结果，再根据反馈修改工作方法，让新任务用上这次的经验。

企业模型、共享知识和工具由管理员配置，你在客户端使用账号已获授权的能力。

## 下载

目前还没有可下载的版本。发布后，安装包会放在 [GitHub 发布页](https://github.com/mumu-github/OpenCoAI-Downloads/releases)，每次更新的改动也会写在那里。

## 安装和更新

Windows 内测包未签名，安装时可能提示“未知发布者”。发布页会附校验文件，安装前请核对下载的文件与 `SHA256SUMS.txt` 中的 SHA-256 值。

更新需要手动下载新安装包。覆盖安装前先备份本机数据，保留账号和会话目录。使用企业模型需要管理员分配的账号，连接地址见企业提供的说明。

遇到问题，可以在 [Issues](https://github.com/mumu-github/OpenCoAI-Downloads/issues) 写下系统版本、客户端版本和复现步骤。请不要附上密码或企业资料。
